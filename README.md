# IT CHAOS CHECK™

A completely free, funny, interactive IT personality quiz with **six screens**.

## Six screens
1. **The 404 welcome screen:** Enter a nickname.
2. **Wi-Fi meltdown:** Pick a ridiculous helpdesk response and get instant feedback.
3. **Overconfidence meter:** Drag an interactive slider to rate your tech skills.
4. **Phishing test:** Resist the totally-not-suspicious free-RAM scam. The unsafe option plays a joke on you.
5. **Printer boss fight:** Try to fix a haunted printer three times.
6. **Personalized certificate:** See one of four IT archetypes, with animated confetti, replay and challenge-a-friend sharing.

Fully responsive. No accounts, tracking, ads, frameworks, external fonts, or paid services required. The optional sound can be turned on or off.

## Publish for free with GitHub Pages

1. Go to https://github.com/new and create a **public** repository named `it-chaos-check`.
2. Use **Add file → Upload files** to upload **index.html**, **style.css**, and **script.js** (not the ZIP file). Click **Commit changes**.
3. Under your repository's **Settings → Pages → Build and deployment**, select **Deploy from a branch**.
4. Choose branch **main**, folder **/(root)**, and click **Save**.
5. Your free website should become available at `https://YOUR-USERNAME.github.io/it-chaos-check/` once GitHub finishes publishing.
6. Share that link with friends. It works on mobile phones and desktops. Each visitor gets their own independent game.

GitHub Pages is available free for public repositories, subject to GitHub's policies and limits. No custom domain is required.

## Test locally
Open `index.html` in any modern browser. The full quiz works locally. Sharing a public link only works *after* you publish online.

## Personalize it
Edit the wording in `script.js`, the colours in `style.css`, or the title in `index.html`.

## Privacy
No server, forms, analytics, or database. Nicknames and quiz answers stay on the current browser page. A person's name can be included in a challenge link under the `challengedBy` URL parameter when they choose to share; don't enter private information as a nickname.
